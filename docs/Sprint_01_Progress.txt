SPRINT 1 IMPLEMENTATION STATUS
Updated: 12 October 2026

Sprint 1 is in progress. This is a foundation implementation, not a claim that
the full particle core or either platform certification gate is complete.

Implemented and locally exercised
- C++20/CMake 3.28+ source layout, Ninja presets, fixed dependency commits and
  a local Git repository on codex/sprint-1-foundation.
- SDL3 native window lifecycle and a small native-handle adapter. bgfx owns
  the Metal layer; no second SDL Metal layer is created.
- Explicit Metal/D3D11 selection with backend fallback disabled. Compute,
  binding/instance limits and diagnostic image support are checked at runtime.
- Backend shaderc build rules and executable-relative assets. macOS assets
  are in bundle Resources, matching SDL_GetBasePath behavior.
- An ImGui SDL3 platform backend and project bgfx renderer with font texture,
  scissor, index offsets, framebuffer scaling and deferred resource destruction.
- GPU reset, ping-pong gravity/drag/analytic box contacts and instanced rendering
  of 16,384 seeded particles. Compute views 0-4 precede draw views 10 and 20.
- A 64-byte particle ABI, 32-byte packed render record, stable ID/generation
  authoring fields, CPU command validation and fixed 1/60-second scheduling.
- Pause, single tick, seeded reset, orbit controls and CPU/GPU frame-time display.
- CPU invariant tests, a real-device GPU ABI test and bounded --frames runs.
- A Windows/macOS CI workflow for builds, shaders, CPU tests and artifacts.
  The workflow is authored locally; it has not run on a remote CI service.

Verified evidence
- Local machine: Apple M3 Max, 48 GB unified memory. This is not the design's
  M1 Pro reference tier, and these checks are not performance certification.
- Release configuration and compilation completed with AppleClang 21 and Metal.
- CTest core_invariants passed in CPU-only and full application builds.
- --gpu-test passed exact 64-byte round trips for counts 1, 127, 128 and 129
  through GPU reset and export passes. This verifies ABI and ordered compute
  visibility; it does not certify a free list or the future granular solver.
- --frames 600 completed and shut down cleanly after 302 fixed ticks.
- The final GPU suite additionally passed gravity, drag, floor/box contacts,
  finite-state and identity preservation against a CPU reference at all four
  particle counts (relative/absolute float tolerance 1e-5).
- Normal FetchContent downloads completed and exact bgfx/bx/bimg submodule
  commits were verified; the final build no longer uses the temporary checkout.
- SDL archive builds use the pinned SDL revision rather than probing parent Git.
- Packaged app smoke test launched from /tmp completed 600 frames and 305 ticks.
  All 7 packaged shader manifests match their binary SHA-256 hashes; 8 dependency
  license notices are included. Runtime dynamic links are system libraries only.
- Local package: out/macos-release/ParticleWorld.app (not distribution-signed
  or notarized). Source build and package both use bundle Resources/assets.
- Native visual inspection showed particles and readable ImGui controls.
- UI verification: single-step paused at tick 583, the next click advanced to
  584, and reset while paused returned to tick 0 and restored the seeded cloud.
- Native window zoom/restore preserved drawing and UI; close exited cleanly.
- Synthetic-click testing exposed stale mouse position in global polling.
  Button event coordinates are now queued before the ImGui button event, and
  the pause/single-step/reset checks passed afterward.

Open gates
- Windows/D3D11 build and real-device execution are unverified.
- Ten-minute soak, zero/max-capacity/full-pool tests and million-particle
  benchmark have not been completed.
- No baseline p95 target is claimed. The current demo has no pair contacts.
- Readback is limited to explicit startup/GPU tests; the steady-state scene
  performs no full-particle readback.
